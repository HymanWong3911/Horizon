## [Quick Study Turns Photos into Animated Oil Paintings](https://simonwillison.net/2026/Oct/23/quick-study-painter/) ⭐️ 5.0/10

Simon Willison shared Quick Study, a Claude Opus 5.5 High-built canvas tool that takes an uploaded photo and animates a simulated oil-painting version in a few seconds. The project was generated from a short prompt and uses Sobel edge detection to guide the painting effect. It shows how AI-assisted creative coding can quickly produce polished, browser-based visual effects with minimal dependencies. The tool may inspire creators making short videos, interactive visuals, or stylized image effects, though it remains a niche experiment rather than a commercial platform. Quick Study runs in an HTML canvas and uses the Sobel operator to detect edges that shape the simulated brushwork. Its only external dependency is Google Fonts, and it follows Willison’s earlier August 2026 experiment in which Claude Fable created a watercolor simulation with P5.js.

rss · Simon Willison · Oct 23, 21:35

**Background**: The Sobel operator is an image-processing technique that calculates horizontal and vertical brightness gradients to emphasize edges. The HTML Canvas API allows JavaScript to draw and animate graphics directly in a web browser. P5.js is a creative-coding library commonly used for visual experiments, although the new Quick Study tool avoids such libraries apart from fonts.
