## [Z.ai Releases Top Open Text LLM GLM-5.2](https://simonwillison.net/2026/Jun/17/glm-52/#atom-everything) ⭐️ 6.0/10

On June 16, 2026, Chinese AI lab Z.ai published the full open weights of its text-only GLM-5.2 LLM under an MIT license, after first rolling out the model to coding plan subscribers on June 13. The newly released model immediately ranked as the leading open text LLM across multiple widely recognized independent industry benchmarks at launch. This model breaks the previous performance ceiling of open weight LLMs, offering teams and developers a far more capable fully open alternative to closed commercial LLMs at a much lower inference cost, which will accelerate innovation across local AI deployment, open source AI tooling and enterprise private LLM use cases. GLM-5.2 is a 753B total parameter Mixture of Experts model with 40B active parameters per token, a 1 million token context window, and it ranks 1st on Artificial Analysis Intelligence Index v4.1 and 2nd on the Code Arena WebDev leaderboard, though it consumes significantly more output tokens per task than other competing top open LLMs.

rss · Simon Willison · Jun 17, 23:58

**Background**: Mixture of Experts (MoE) is a widely adopted LLM architecture that activates only a small subset of total model parameters for each input token, which allows developers to build far larger and more capable models without the excessive inference cost of a fully dense large model. Open weight LLMs refer to models whose full trained weights are publicly released, so users can run, modify and deploy the model entirely on their own hardware instead of relying on third-party API services.
